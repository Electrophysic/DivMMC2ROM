# DivMMC2ROM
![Div](DivElPh.jpg)
DivMMC на дисктретной логике. Основное отличие от проекта Алекса это наличие двух ПЗУ вместо одного. Одно хранит прошивку, другое выступает в роли дешифратора адреса.
Также реализован независимый порт Z controller. Див и z работают одновременно, не нужно ничего переключать.
